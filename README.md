# Обрій

Інтерактивна супутникова карта 27 адміністративних регіонів України: 24 області, АР Крим, місто Київ і місто Севастополь. Супутникові плитки промальовуються лише всередині кордону України; за ним показано тонкі контури регіонів на темному фоні. Район України видно лише за наявності активної тривоги в підключених даних. **Джерело поточних тривог і дані про пуски ще не підключені.**

## Запуск

```sh
python3 -m http.server 8000
```

Відкрийте `http://localhost:8000`. Leaflet і геодані зберігаються локально; для супутникових знімків потрібен доступ до сервісу Esri World Imagery. Для шрифтів потрібне з'єднання з Google Fonts; без нього працюють системні шрифти.

## Керування

- Натисніть на регіон, щоб виділити його й побачити назву. Регіони також доступні з клавіатури.
- Введіть назву регіону та натисніть Enter для пошуку.
- Кнопка «Показати всю Україну» повертає огляд; кнопки праворуч змінюють масштаб. Карту також можна пересувати та масштабувати коліщатком або жестами.
- Кнопка шарів праворуч перемикає супутниковий і темний вигляд. Обраний вигляд зберігається в браузері. Підписи областей стають дрібнішими й поступово зникають під час віддалення; на далекому огляді залишається Київ.

## Геодані

Файли [`data/ocha-adm0.geojson`](data/ocha-adm0.geojson), [`data/ocha-adm1.geojson`](data/ocha-adm1.geojson) і [`data/ocha-adm2.geojson`](data/ocha-adm2.geojson) завантажено з публічного сервісу [OCHA UKR Simplified Boundaries](https://gis.unocha.org/server/rest/services/Hosted/UKR_Simplified_Boundaries/FeatureServer). Шар ADM0 задає контур України для затемнення сусідніх країн, ADM1 — межі областей, ADM2 — геометрію районів. [`tools/build_map.py`](tools/build_map.py) розміщує підписи всередині областей та створює [`data/map-regions.json`](data/map-regions.json). Після оновлення геоданих виконайте `python3 tools/build_map.py`.

Зовнішні межі походять із [geoBoundaries gbOpen](https://www.geoboundaries.org/), версія репозиторію `9469f09`. Похідні, геометрично спрощені файли ADM1 лежать окремо за країнами в [`data/external-admin1`](data/external-admin1); контур Молдови ADM0 — у [`data/external-admin0`](data/external-admin0). Їх створює [`tools/build_external_regions.py`](tools/build_external_regions.py). Для Росії використано 83 регіони з набору 2017 року, без Криму й інших українських територій. Молдову показано одним контуром і підписом, щоб уникнути скупчення дрібних районів; Польщу, Угорщину й Румунію — приблизно до половини країни з приглушенням дальніх контурів. Для Білорусі й Словаччини залишено прикордонні регіони. Роки вихідних наборів різняться; ці межі — картографічний контекст, не оперативні дані.

Джерела та умови використання похідних файлів: [Росія](https://www.geoboundaries.org/api/current/gbOpen/RUS/ADM1/), [Польща](https://www.geoboundaries.org/api/current/gbOpen/POL/ADM1/) і [Словаччина](https://www.geoboundaries.org/api/current/gbOpen/SVK/ADM1/) — ODbL 1.0; [Білорусь](https://www.geoboundaries.org/api/current/gbOpen/BLR/ADM1/) — CC BY 3.0; [Румунія](https://www.geoboundaries.org/api/current/gbOpen/ROU/ADM1/) і [Молдова](https://www.geoboundaries.org/api/current/gbOpen/MDA/ADM0/) — CC BY 4.0; [Угорщина](https://www.geoboundaries.org/api/current/gbOpen/HUN/ADM1/) — CC0 1.0. Автори та вихідні джерела вказані у відповідях API. При регенерації зберігайте ці атрибуції й ліцензії.

Підкладка — [Esri World Imagery](https://services.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer). Атрибуція Esri, OCHA та geoBoundaries показана на карті. Бібліотека [Leaflet 1.9.4](https://leafletjs.com/download.html) зберігається у `vendor/`.

Контури є адміністративними межами й не позначають контроль територій або лінію фронту. Крим і Севастополь входять до карти України.

## Статус тривог

Сторінка кожні 30 секунд читає [`data/alerts.json`](data/alerts.json). Формат для серверного адаптера:

```json
{
  "connected": true,
  "updatedAt": "2026-09-23T13:56:26Z",
  "activeDistrictCodes": ["UA3208"]
}
```

Коди районів — значення `adm2_pcode` з набору OCHA. Якщо файл не оновлювався понад три хвилини або джерело недоступне, активні контури прибираються і карта показує стан «дані застаріли» чи «не підключені». Приклад вище описує формат, а не поточну тривогу.

## Наступний етап

Для реальних тривог потрібен серверний адаптер до погодженого джерела, наприклад [alerts.in.ua API](https://devs.alerts.in.ua/), із захищеним токеном, обмеженням запитів, часом оновлення та явним станом «немає даних». Дані DeepState не включені без погодженого способу доступу.
