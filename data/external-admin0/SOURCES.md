# Moldova country contour

`MDA.geojson` is a simplified derivative of [geoBoundaries gbOpen Moldova ADM0](https://www.geoboundaries.org/api/current/gbOpen/MDA/ADM0/) at repository revision `9469f09`, original dataset year 2014, under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The source API identifies the original contributors. Its single country contour replaces the crowded ADM1 raion labels at this map scale.
